# SimpleGUI 设计台：空白工程三级菜单搭建指南

目标：从 `blank` 模板开始，做出一个可在模拟器里直接测试的三级菜单，并且后续能导出对应代码思路。

## 1. 新建空白工程

1. 打开设计台后，在顶部模板切换里选择 `空白工程`。
2. 确认左侧工程树里只有一个 `Main` 页面。
3. 保持屏幕尺寸为 `128x64`，先不要改模拟器分辨率。

## 2. 放置一级菜单

1. 从左侧控件库拖入一个 `menu` 控件到画布。
2. 选中它，在右侧属性面板把名称改成 `Main Menu`。
3. 把菜单位置放在左上角，常见起点是 `x=0, y=0`。
4. 在菜单条目里添加 3 到 6 项，先用英文占位文本也可以。

推荐结构：

- `File`
- `Edit`
- `View`

## 3. 放置二级菜单

1. 再拖入一个 `menu` 控件，命名为 `Sub Menu`。
2. 让它的 `父级控件` 指向一级菜单。
3. 先把它设为不可见，模拟器里由一级菜单确认键触发打开。
4. 给它添加一组子项，例如 `New`、`Open`、`Save`。

## 4. 放置三级菜单

1. 再拖入第三个 `menu` 控件，命名为 `Sub Sub Menu`。
2. 让它的 `父级控件` 指向二级菜单。
3. 先保持隐藏，由二级菜单的确认键打开。
4. 添加更深一层的条目，例如 `Project`、`Template`、`Recent`。

## 5. 绑定交互规则

1. 在规则面板里给一级菜单加 `Up` / `Down` 选择动作。
2. 给一级菜单的 `Confirm` 动作绑定“打开二级菜单”。
3. 给二级菜单的 `Confirm` 动作绑定“打开三级菜单”。
4. 给 `Esc` 绑定返回上一级或关闭当前弹出菜单。

最小语义建议：

- 一级菜单按 `Enter` 打开二级菜单。
- 二级菜单按 `Enter` 打开三级菜单。
- `Esc` 优先关闭当前最深层菜单。

## 6. 调整布局

1. 用鼠标拖动每个菜单到正确位置。
2. 用四角和边缘手柄微调宽高。
3. 菜单项太多时，优先减小字体或减少可见项数。
4. 如果你想做“像官方 demo 那样”的效果，先保证每个菜单都能被模拟器键盘完整走通。

## 7. 验证方式

1. 切到模拟模式。
2. 用方向键移动选中项。
3. 按 `Enter` 逐层展开菜单。
4. 按 `Esc` 回到上一级。
