# 设计文件驱动工作流（不改源码）

目标：以后每次做新界面/交互，只通过导入 `project.json` 完成，不再改设计台源码。

## 1. 现成示例文件

已提供可直接导入的三级菜单示例：

- `doc/examples/blank_3level_menu_3x3.project.json`

导入后可直接：

- 在画布继续编辑控件和参数
- 在模拟器里直接联调按键交互
- 再导出成新的设计文件

## 2. 使用步骤

1. 启动设计台（`npm run dev` 或双击 `launch_designdesk.bat`）。
2. 顶部点击“打开”，选择一个设计文件（`.json`）。
3. 进入编辑模式修改页面、控件、规则。
4. 切到模拟模式验证交互。
5. 顶部点击“保存”导出新文件，作为下一轮基线。

## 3. 设计文件规范（最关键）

- 根字段必须为 `version: 1`
- 屏幕固定 `128x64`
- `pictures` / `widgets` / `rules` 的 `id` 必须唯一
- 规则里引用的 `pictureId` / `widgetId` / `variableId` / `timerId` 必须存在
- 推荐把一条复杂交互拆成多条小规则，便于定位问题和后续导出 C 代码

## 4. 推荐协作方式

1. 你描述需求（页面结构 + 交互目标）。
2. 我先产出一个可导入设计文件。
3. 你导入后在设计台二次微调。
4. 你把“调好后的设计文件”发我。
5. 我再按最终文件生成/移植 MSPM0G3507 代码。

这样可以保证“你看到全过程、能随时改、项目可复用”。
